# Cash Rush

Jeu clicker navigateur (argent **virtuel** uniquement).

## Jouer

Ouvre `index.html`, ou la page GitHub Pages du dépôt.

## Monétisation créateur

- Pubs / skins : config dans `monetization.js`
- Les joueurs ne retirent pas de vrai argent
- Les vrais paiements créateur passent par AdSense / Stripe (hors jeu)

## Banque virtuelle

Le bouton « Retirer » envoie l’argent vers une banque **dans le jeu** seulement.
